# Contribuir a MisFinanzas

Gracias por tu interés en mejorar MisFinanzas.

## Antes de comenzar

1. Revisa el README y la documentación de arquitectura.
2. Abre un issue para explicar errores o proponer cambios importantes antes de implementarlos.
3. Crea una rama para tu cambio y envía un pull request con una descripción clara.
4. Ejecuta las pruebas unitarias y Android Lint siguiendo las instrucciones del README.
5. No incluyas credenciales, claves, datos financieros reales ni información personal en commits, pruebas o capturas.

## Pull requests

Describe qué cambiaste, por qué fue necesario y cómo lo verificaste. Mantén cada cambio enfocado y respeta la arquitectura existente.

Las contribuciones aceptadas se distribuyen bajo la licencia Apache 2.0 del repositorio. Conserva los avisos de derechos de autor y licencias de terceros que correspondan.
